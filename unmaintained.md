# Unmaintained

These were on the main list and are not maintained any more — the repository is
archived, or nothing has been pushed to it in years.

They are kept here rather than deleted because several of them are still the
only option for what they do, and knowing that a thing exists but is abandoned
is more useful than not finding it at all. None of them should be a first
choice, and each one names what to reach for instead.

## Clients

- [PHP 7](https://github.com/aerospike-community/aerospike-client-php) - Community client for the PHP 7 series. Archived. The [official PHP 8 client](https://github.com/aerospike/php-client) replaces it.
- [Scala](https://github.com/Tinkoff/aerospike-scala) - Typesafe DSL over the Java client. Archived, with no successor — the [Java client](https://github.com/aerospike/aerospike-client-java) is what Scala code uses now.

## Deployment

- [travelaudience Operator](https://github.com/travelaudience/aerospike-operator) - An independent Kubernetes operator, predating the official one. Archived; use the [Aerospike Kubernetes Operator](https://github.com/aerospike/aerospike-kubernetes-operator).

## Monitoring

- [asprom](https://github.com/alicebob/asprom) - An independent Prometheus exporter, smaller in scope than the official one. Archived; use the [Prometheus Exporter](https://github.com/aerospike/aerospike-prometheus-exporter).

## Connectors

- [aerospark](https://github.com/sasha-polev/aerospark) - Community Spark connector. Last touched in 2017; use the [supported Spark connector](https://aerospike.com/docs/connect/spark).
